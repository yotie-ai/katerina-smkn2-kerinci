# KATERINA v3 — SMKN 2 KERINCI

## Isi
- index.html — aplikasi PWA
- manifest.webmanifest — instalasi sebagai aplikasi
- sw.js — cache/offline dasar
- icon.svg — ikon aplikasi
- supabase_schema.sql — struktur database kelas
- SETUP_DATABASE.txt — panduan database terpusat

## Publikasi dengan GitHub Pages
1. Buat repository Public, misalnya `katerina-smkn2-kerinci`.
2. Upload semua file di folder ini ke root repository.
3. GitHub → Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: `main`, folder: `/ (root)`.
6. Save.
7. Setelah deployment, GitHub menyediakan tombol Visit site.

Pola URL:
https://USERNAME.github.io/katerina-smkn2-kerinci/

## Instal di HP
Buka URL di Chrome Android → menu ⋮ → Instal aplikasi/Tambahkan ke layar utama.

## Database
Untuk mengumpulkan data seluruh siswa ke dashboard guru, konfigurasi Supabase sesuai SETUP_DATABASE.txt.
